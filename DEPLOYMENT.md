# RailPredict AI — Deployment Guide (Phase 0)

A step-by-step checklist to get from this repo to a live URL.

---

## Prerequisites

- [x] GitHub account and this repo pushed to GitHub
- [x] [Render account](https://render.com) (free tier is fine)
- [x] [Vercel account](https://vercel.com) (free tier is fine)
- [x] [Timescale Cloud account](https://www.timescale.com/cloud) (free 30-day trial, then ~$25/month for the smallest instance — check current pricing)
- [x] [Upstash account](https://upstash.com) (free tier Redis, works with Streams)

---

## Step 1 — Create Timescale Cloud Database

1. Log in to Timescale Cloud → **New Service** → choose a region close to India (e.g. AWS ap-south-1 / Mumbai)
2. Note your connection string. It will look like:
   ```
   postgresql://tsdbadmin:PASSWORD@HOST.tsdb.cloud.timescale.com:PORT/tsdb
   ```
3. Convert it to the asyncpg scheme for the API:
   ```
   postgresql+asyncpg://tsdbadmin:PASSWORD@HOST.tsdb.cloud.timescale.com:PORT/tsdb
   ```

---

## Step 2 — Create Upstash Redis

1. Log in to Upstash → **Create Database** → choose the same region
2. Copy the **Redis URL** (starts with `rediss://` — note the double `s` for TLS)

---

## Step 3 — Deploy the API to Render

### Option A — Blueprint (recommended)

1. In the Render dashboard: **New** → **Blueprint**
2. Connect your GitHub repo
3. Render detects `render.yaml` automatically
4. After creation, go to the `railpredict-api` service → **Environment**:
   - Set `DATABASE_URL` to your Timescale Cloud connection string (asyncpg scheme)
   - Set `REDIS_URL` to your Upstash Redis URL
   - Set `CORS_ORIGINS` to `https://your-vercel-app.vercel.app` (fill in after Step 4)
   - `JWT_SECRET_KEY` is auto-generated by Render — no action needed
5. Trigger a manual deploy; wait for it to go green
6. Copy the Render API URL: `https://railpredict-api.onrender.com`

### Option B — Manual Web Service

1. **New** → **Web Service** → connect repo
2. **Runtime**: Docker | **Dockerfile path**: `services/api/Dockerfile` | **Context**: `services/api`
3. Add env vars as above

---

## Step 4 — Deploy the Frontend to Vercel

1. Go to [vercel.com/new](https://vercel.com/new) → import your GitHub repo
2. **Root Directory**: `apps/web`
3. **Framework Preset**: Next.js (auto-detected)
4. Add environment variable:
   - `NEXT_PUBLIC_API_URL` = `https://railpredict-api.onrender.com`
5. Also create a **Vercel environment secret** named `railpredict-api-url` with the same value (used by `vercel.json`)
6. Deploy → copy your Vercel URL

---

## Step 5 — Update CORS on Render

Go back to Render → `railpredict-api` service → Environment:
- Update `CORS_ORIGINS` to your Vercel URL (e.g. `https://railpredict.vercel.app`)
- Trigger a redeploy

---

## Step 6 — Smoke Tests

Run these manually after deploy:

```bash
# 1. Liveness
curl https://railpredict-api.onrender.com/healthz
# Expected: {"status":"ok","version":"0.1.0"}

# 2. Readiness (DB connected)
curl https://railpredict-api.onrender.com/readyz
# Expected: {"status":"ok","db":"connected"}

# 3. Bad login returns 401
curl -X POST https://railpredict-api.onrender.com/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"nobody@example.com","password":"badpassword"}'
# Expected: 401 {"detail":"Invalid credentials"}

# 4. Frontend loads and shows "API Online" badge
# Open https://your-app.vercel.app in a browser
```

## Local Development

```bash

cd infra
docker compose up --build

# 3. Check health
curl http://localhost:8000/healthz
curl http://localhost:8000/readyz

# 4. Frontend
open http://localhost:3000
```

## Seeding an Admin User (local only)

```bash
# Run a Python one-liner inside the API container
docker compose exec api python -c "
import asyncio
from app.core.database import AsyncSessionLocal
from app.core.security import hash_password
from app.models.user import User

async def seed():
    async with AsyncSessionLocal() as db:
        user = User(email='admin@railpredict.dev', password_hash=hash_password('changeme123'), role='admin')
        db.add(user)
        await db.commit()
        print('Seeded admin user')

asyncio.run(seed())
"
```

Then test login:
```bash
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@railpredict.dev","password":"changeme123"}'
```
